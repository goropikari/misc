# Agents

このプロジェクトにおける Matcher 実装（エージェント）の役割について記述します。

## Matcher インターフェース

パスとメソッドに基づいたリクエストのルーティングと、それに関連付けられたハンドラの実行を定義します。

## 実装一覧

### MuxMatcher

- **役割**: 高機能なパスマッチング。
- **特徴**:
  - `http.ServeMux` を利用。
  - ワイルドカード（パターン）マッチングをサポート（例: `/user/{id}/hoge`）。
  - HTTP メソッドによるフィルタリングをサポート。
- **ユースケース**: 動的なパスパラメータが必要な複雑な API ルーティング。

### SimpleMatcher

- **役割**: シンプルで高速な完全一致マッチング。
- **特徴**:
  - Go の `map` を利用して `method:path` の組み合わせで管理。
  - 文字列の完全一致のみを判定。
- **ユースケース**: パスパラメータが不要で、パフォーマンスが重視される固定パスのルーティング。
